# 快速对话与任务停止

左侧 **对话** → **新建对话** 进入 Quick Chat。适合查资料、解释代码、写小脚本或讨论研究问题；不要求先创建项目或运行完整流水线。

## 对话组织与批量操作

对话可重命名、搜索、移动到文件夹。MiraUI 0.4.5rc1 加入批量选择：

- `⌘`（macOS）/ `Ctrl`（Windows/Linux）点击：添加或取消单条选择。
- `Shift` 点击：按当前可见列表选择一段连续对话。
- 选中后使用批量移动或删除；搜索或切换工作区/列表后应重新确认选择范围。

![对话文件夹与批量选择工具](/img/current/chat-selection.png)

*当前对话列表的局部截图，标题为演示数据。*

删除对话会先确认：从列表中移除对话，**不会删除磁盘上的历史文件**。批量操作部分失败时，界面报告成功/失败数量，可重试失败项。

## 在消息中指定 Skill

消息输入区可以为本次消息选择 Skill。明确选中的 Skill 会作为当前任务的指令加载；如果技能不能继续执行，MIRA 会先请求你批准替代方案，再走 fallback。

技能与插件的安装/可用范围见 [Skills 与 Tools](../agent-config/skills-and-tools.md)。选择 Skill 不代表数据、模型或依赖已经配置好，仍需检查实际工具结果。

## 输入与停止

设置中可以选择 **Enter 发送** 或 **Shift+Enter 发送**，消息输入框可调整高度；流式回复也可在设置中开关。

运行中点击 **停止**，客户端向引擎请求取消当前会话中的活动任务。引擎会处理子智能体与后台 shell 任务，并返回停止确认。按钮点击与后端确认之间可能有短暂等待；检查确认状态后再开始新的任务。

停止当前任务不会卸载或关闭整个引擎。需要停止本机服务时使用桌面设置中的 **停止引擎**，见 [本地服务](../../deployment/local-engine-service.md)。

## 转为研究项目

当快速对话需要长期保存实验与产出时，可使用 **转为研究项目**：

1. 查看从对话预填的项目目标。
2. 检查项目创建信息与要带入的对话上下文。
3. 创建项目后，源对话作为独立 Markdown 上下文附件保存，供后续研究读取。
4. 在项目总览中选择从调研、实验或交付开始。

上下文附件与“本次运行目标”分开保存，便于保留讨论过程。它不等于自动继承其他 ModuleRun 的完整会话；模块间传递以显式选中的产物和摘要为主。
