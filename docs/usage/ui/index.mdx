## 三个容易混淆的操作

- **选择候选**：改变当前要查看或继续使用的结果，不会重跑上游。
- **用此候选继续**：创建新的下游 ModuleRun，带入所选结果，保留已有分支。
- **批准并继续**：回答当前运行中的确认表单，继续同一个 ModuleRun。

项目总览的“模块完成后”控制下游衔接；实验启动窗口中的“实验执行模式”控制同一次实验运行内是否逐个等待确认。两者独立。
